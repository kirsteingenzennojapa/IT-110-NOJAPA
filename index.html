20 HTML Tags I Learned

HTML Tags and Their Uses

  • html - used to create an HTML document
  • head - contains information about the webpage
  • title - gives a title to the webpage
  • body - contains the content of the webpage
  • h1 - used for the main heading
  • h2 - used for a smaller heading
  • p - used to create paragraphs
  • strong - makes important text bold
  • ul - creates an unordered list
  • li - creates an item in a list
  • header - defines the header of a webpage
  • nav - creates a navigation section
  • a - creates a hyperlink
  • main - defines the main content
  • section - groups related content
  • article - defines independent content
  • h3 - creates a third-level heading
  • em - emphasizes text
  • br - creates a line break
  • footer - defines the footer of a webpage

HTML is used to create the basic structure of a webpage. HTML tags help organize the content of a website.
